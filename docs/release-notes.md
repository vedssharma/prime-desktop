## Install Session Dock {{VERSION}}

Session Dock is an unofficial desktop companion for the Prime Agent CLI. Install and log in to `prime-agent` first; Session Dock uses its sessions, credentials and models. **Not affiliated with or endorsed by Prime Intellect.**

| Platform | Download |
| --- | --- |
| macOS, Apple Silicon | `Session-Dock-{{VERSION}}-mac-arm64.dmg` |
| Ubuntu / Debian (x64) | `Session-Dock-{{VERSION}}-linux-amd64.deb` |
| Other Linux (x64) | `Session-Dock-{{VERSION}}-linux-x86_64.AppImage` |

These builds are **not signed or notarized**. On macOS, the first launch needs one extra step (Control-click the app and choose **Open**). See the [install guide](https://github.com/vedssharma/prime-desktop#install) for every platform, and check downloads against `SHA256SUMS`.

Intel Macs and Windows are not supported yet.
